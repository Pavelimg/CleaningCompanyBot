# Cleaning Service Telegram Bot

Асинхронный Telegram-бот для оформления и распределения заявок клининговой компании. В проекте реализованы отдельные пользовательские сценарии для клиента, администратора и рабочей бригады.

## Возможности

- пошаговая регистрация клиента и сохранение адреса;
- выбор услуг из прайс-листа и формирование заявки;
- просмотр активных заявок клиента;
- очередь свободных заказов для администратора;
- назначение бригады и времени выполнения;
- просмотр заданий бригадой и отметка о завершении;
- хранение пользователей, услуг и заказов в SQLite.

## Стек

Python, aiogram 3, asyncio, SQLite.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```

Перед запуском укажите в `.env` новый токен Telegram-бота. Переменные окружения:

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен, полученный у BotFather |
| `DATABASE_PATH` | путь к SQLite-базе |
| `TELEGRAM_ADMIN_IDS` | Telegram ID администраторов через запятую |
| `TIMEZONE_OFFSET_HOURS` | смещение времени от UTC |

Файл `.env` не должен попадать в Git. Репозиторий не содержит рабочего токена.

## Структура

- `main.py` — обработчики сообщений, callback-запросов и ролей;
- `DBControl.py` — операции с пользователями, услугами и заявками;
- `keyboards.py` — клавиатуры Telegram;
- `config.py` — чтение настроек из переменных окружения.

## Статус

Учебный проект сохранён как пример асинхронного Python-приложения и работы с реляционной моделью данных. Для production-использования необходимы миграции базы, параметризация всех SQL-запросов, логирование и автоматические тесты.
